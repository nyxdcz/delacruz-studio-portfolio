# Design reference

Recreate Nyco's existing Dela Cruz Studio portfolio from the supplied Framer project and its published reference at https://delacruzstudio.framer.website/.

The existing site supplies the direction: a warm grey-green ground (#dcdcd6), deep green typography (#435242), Neue Montreal type, the original DCS wordmark, a monochrome cutout portrait, broad architectural imagery, and generous spacing. The reference's introductory text, biography, project sequence, case-study descriptions, software list, and social destinations are retained. The recreation uses the published biography and project content, with the editor's visible updated introduction.

ENERGY 2 / RHYTHM 3 / MOTION 1. The portrait and oversized introduction provide the opening focal point. A compact software strip leads into an editorial biography and full-width project images. The gallery uses repeated image-led cards because these are comparable portfolio entries. Motion is limited to hover feedback and smooth anchor scrolling, with reduced-motion support. There is no automatic marquee.

The logo and muted green are the identity motif. Uppercase small labels reproduce the reference's editorial section markers. Neue Montreal is retained because it is the source typeface. Rounded outlined action links reproduce the source; fields, image cards, and content surfaces use distinct geometry. Direction arrows identify external destinations. A dark lower image scrim makes white project labels readable over varied source images. The fixed light theme preserves the supplied brand reference.

Responsive layouts retain the image and text hierarchy while stacking the portrait, collapsing navigation into a labelled menu, and keeping controls at least 44px tall. Project pages render the actual full image without cropping. Contact opens a draft to the supplied address, nyxdcz@gmail.com, and makes that behavior explicit.
